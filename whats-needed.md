I actually think you're onto something—but I wouldn't model it as "How much do you like AI?"

That would age poorly. Every major technology (electricity, the internet, smartphones) went through love, fear, hype, disappointment, and normalization. AI will too.

The more interesting question is:

> **How does AI change the way humans think, create, decide, and derive value?**

That's a map that could still be relevant 10–20 years from now.

# If I were writing a book...

I'd probably avoid numbers like Hawkins' 1–1000 scale. Those numbers create an illusion of precision without objective measurement.

Instead, I'd build something that's observable. For each level, define:

| Dimension             | Example                                                      |
| --------------------- | ------------------------------------------------------------ |
| Primary emotion       | Fear, curiosity, confidence, responsibility                  |
| View of AI            | Threat → Tool → Partner → Infrastructure → Civilization  |
| Human role            | Worker → Operator → Collaborator → Architect → Steward   |
| Main question         | "Will AI replace me?" → "What should only humans decide?"   |
| Typical behaviors     | Prompting, reviewing, orchestrating, governing               |
| Common failure mode   | Denial, over-reliance, automation without judgment           |
| Signal of progression | What changes before someone naturally reaches the next level |

That makes the model testable through behavior rather than belief.

One idea I find especially compelling is that  **the highest stages aren't defined by how much AI someone uses, but by how much responsibility they accept for directing intelligence** . In earlier eras, leadership meant managing people and resources. In the AI era, leadership increasingly means managing  *human and machine intelligence together* . That's a shift substantial enough to justify an entirely new map. It moves beyond "AI adoption" into a broader question: **what does it mean to be an increasingly conscious human when intelligence is no longer exclusively human?** That feels like a model with the potential to remain relevant even as today's AI systems become tomorrow's ordinary tools.
