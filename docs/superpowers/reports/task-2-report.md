## Choices Made

1. **ASCII diagram layout** — Used a 2×2 quadrant grid with text axis labels rather than a Unicode box-drawing chart, to ensure reliable monospace rendering across Markdown renderers. The persona names are placed inside their respective quadrants with whitespace separation.

2. **Prompt 1 brevity** — The AI Capability level descriptions were kept short (one line each) to stay within the word-count target for the section. The Glossary's axis level-lists at the end of the file serve as the verbatim reference, so the assessment prompts don't need to repeat full definitions.

3. **Register** — Kept declarative and plain throughout. No rhetorical questions, no hype, no hedging. The self-assessment is framed as a positioning exercise ("a dot and an arrow"), not a quiz.

4. **"~" on word count** — The spec says "~400–550 words" for the Locate Yourself section. The final count is 536 words, which treats the tilde as permitting up to ~550. If stricter adherence is needed, the closing paragraph of Prompt 3 can be shortened further without losing meaning.

5. **Z-axis** — Purpose / Scope (Self → Team → Org → Industry → Society → Humanity) is included in the glossary axis-levels section verbatim but not woven into the diagram or the self-assessment prompts, since the map figure is a 2D representation and the Z-axis is a depth dimension that the later chapters can develop. This is consistent with the brief, which only requires it in the glossary.
