When intelligence becomes abundant and cheap, judgment becomes scarce. A two-axis map for finding the human value that survives AI: where your leverage goes when the machine can produce the answer, how that leverage collapses without anyone noticing, and how to defend the faculty it depends on. The full designed PDF.

## How it is built

The front matter and the closing author page are generated by
[book-forge](https://github.com/asadani/book-forge) from one shared source, so
they are identical across every book on the shelf:

```
bf inject     render the matter into book.html.in
bf build      html -> headless Chrome -> folio-stamped, self-audited PDF
```
